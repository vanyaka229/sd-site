# Заявки с сайта прямо в Telegram — пошагово

Схема: форма на сайте → Cloudflare Worker (посредник) → ваш Telegram **@sd_dancestudio**.

Почему нужен посредник: токен бота — это пароль. Если положить его в код сайта, любой
посетитель увидит его и сможет рассылать сообщения от имени бота. Поэтому токен хранится
в переменных воркера, а сайт знает только его адрес.

Всё бесплатно: Cloudflare Workers даёт 100 000 запросов в сутки на бесплатном тарифе.

---

## Шаг 1. Создать бота и получить токен

1. Откройте Telegram, найдите **@BotFather**, нажмите **Start**.
2. Отправьте `/newbot`.
3. Придумайте имя бота (например, `SD Studio Заявки`) и юзернейм, заканчивающийся на `bot`
   (например, `sd_studio_forms_bot`). Юзернейм должен быть свободен.
4. BotFather пришлёт строку вида:

   ```
   Use this token to access the HTTP API:
   7123456789:AAH3k...Qw9E
   ```

   **Это и есть токен** — сохраните его, он понадобится на шаге 4.

## Шаг 2. Написать боту от своего аккаунта

Откройте чат со своим новым ботом (ссылка вида `https://t.me/sd_studio_forms_bot`)
**с аккаунта @sd_dancestudio** и нажмите **Start** / отправьте любое сообщение.

Бот не может написать первым — без этого шага заявки не дойдут.

## Шаг 3. Узнать chat_id

Вставьте в адресную строку браузера (подставив свой токен) и откройте:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

В ответе найдите:

```json
"chat": { "id": 123456789, "first_name": "..." }
```

Число `123456789` — это ваш **chat_id**. Если ответ пустой (`"result":[]`), напишите боту
ещё одно сообщение и обновите страницу.

> Если заявки должны идти в **канал или группу**: добавьте бота туда администратором,
> отправьте в чат любое сообщение и возьмите `id` из `getUpdates` — он будет отрицательным,
> например `-1001234567890`.

## Шаг 4. Развернуть воркер

1. Зарегистрируйтесь на [cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатно).
2. Слева выберите **Workers & Pages** → **Create** → **Worker** → задайте имя
   (например, `sd-studio-form`) → **Deploy**.
3. Нажмите **Edit code**, удалите шаблон и вставьте содержимое файла
   [`telegram-worker.js`](telegram-worker.js) из этой папки → **Deploy**.
4. Откройте **Settings → Variables and Secrets** и добавьте три переменные
   (тип **Secret** для токена):

   | Имя | Значение |
   | --- | --- |
   | `BOT_TOKEN` | токен из шага 1 |
   | `CHAT_ID` | id из шага 3 |
   | `ALLOWED_ORIGIN` | адрес сайта, например `https://sd-dance-st.ru` |

5. Сохраните и нажмите **Deploy** ещё раз, чтобы переменные применились.
6. Скопируйте адрес воркера — он вида
   `https://sd-studio-form.ваш-аккаунт.workers.dev`.

## Шаг 5. Прописать адрес в сайте

Откройте `js/main.js` и впишите адрес воркера в самом верху:

```js
var BOOKING_ENDPOINT = 'https://sd-studio-form.ваш-аккаунт.workers.dev';
```

Загрузите обновлённый файл на GitHub — всё, форма начнёт присылать заявки в Telegram.

## Шаг 6. Проверить

1. Откройте сайт, нажмите «Записаться на занятие», заполните форму, отправьте.
2. В течение пары секунд в Telegram придёт сообщение:

   ```
   Новая заявка с сайта
   Имя: Анна
   Телефон: +7 949 000-11-22
   Группа: Female Dancehall 16+
   Комментарий: ...
   06.10.2026, 01:31 (МСК)
   ```

Если сообщение не пришло:

* проверьте, что вы написали боту (шаг 2);
* откройте адрес воркера в браузере — должен ответить `{"ok":false,"error":"method"}`,
  это значит, что воркер жив, а переменные не проверяются без POST;
* в Cloudflare откройте воркер → **Logs** и посмотрите ответ Telegram: чаще всего
  `chat not found` (неверный `CHAT_ID`) или `Unauthorized` (неверный `BOT_TOKEN`).

---

## Если хостинг не Cloudflare

Тот же воркер легко переносится на Timeweb Apps (раздел App Platform → бэкенд-приложение):
логика та же, только переменные задаются в настройках приложения, а код оборачивается в
маленький HTTP-сервер. Скажите — соберу под Timeweb.
